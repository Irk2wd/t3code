# Updating the privacy fork

Application updates are disabled in the desktop, server, CLI and mobile clients. To update, review the desired commit in your fork, check it out and rebuild it on the machines where you use T3. [Build instructions](./install.md)

The project Git remote and provider model catalogs can still refresh during normal use. Manage agent CLI installations and versions separately with the provider's own tools. [Network destinations](./telemetry.md)

## Continue threads after restarts

Use **Settings → Maintenance → Continue threads after restarts** to resume supported active threads after restarting the host. A thread waiting for your approval, answer or secret still needs your input.
