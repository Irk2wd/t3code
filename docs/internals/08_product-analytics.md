# Network privacy

This fork omits the product-analytics transport and the generators of installation and socket-owner identifiers. A legacy feedback request is refused before gathering thread data. Startup and shutdown do not contact an existing T3 Connect link. Local diagnostics can be inspected by the operator.

The T3 server validates destinations before issuing HTTP requests. The public model manifest uses a dedicated GET without caller-provided headers. Remote HTTP requests cannot follow redirects to a second destination. Desktop renderer sessions filter subresource requests independently of the Node server. The Node policy is installed in the application process and leaves child provider CLIs and Git under their own configuration. [Permitted destinations](../user/telemetry.md)
